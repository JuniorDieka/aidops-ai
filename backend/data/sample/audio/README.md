# Sample Audio File

Due to file size constraints, this directory contains a placeholder for audio files.

In a production deployment, you would place actual audio files (MP3, WAV) here for transcription.

For demo purposes, you can:
1. Record a short audio file discussing humanitarian operations
2. Use text-to-speech to generate a sample audio file
3. Download a Creative Commons licensed audio file

Example audio content for testing:
"This is a field interview from the Northern Region humanitarian response. We spoke with community leaders about the urgent need for clean water access. Currently, families are walking 3 kilometers to reach the nearest water source. Children are missing school to help collect water. We recommend installing at least 5 additional water points within the camp to meet Sphere standards of 15 liters per person per day."

To test audio ingestion:
1. Create or download an MP3/WAV file
2. Place it in this directory
3. Use the frontend upload feature or the sample data ingestion endpoint
