# AidOps AI Screenshots

This folder contains screenshots of the AidOps AI application for non-technical users, policymakers, and program managers to visualize the platform without needing to install or run the application.

## Application Views

### 1. Chat Interface
**File:** `01-chat-interface.png`

The main chat interface where users can ask questions about their humanitarian operations data, request compliance checks, draft reports, or find grant opportunities.

**Features shown:**
- Clean, intuitive chat interface
- File upload button (paperclip icon) for adding documents
- Real-time AI responses with citations
- Navigation sidebar with Chat, Upload Files, and Workflows

---

### 2. Upload Documents
**File:** `02-upload-documents.png`

The document upload interface for ingesting PDFs, audio files, spreadsheets, and other data sources into the knowledge base.

**Features shown:**
- Drag-and-drop file upload
- Support for PDF, MP3, WAV, CSV, XLSX formats
- "Load Sample Data" button for quick demo
- Clear instructions for users

---

### 3. Agent Workflows
**File:** `03-agent-workflows.png`

The autonomous workflow execution interface powered by LangChain agents.

**Features shown:**
- **Compliance Check** - Cross-reference operational data against global standards
- **Report Drafting** - Generate structured reports from raw notes
- **Grant Matching** - Find funding opportunities for your projects
- **Crisis Monitor** - Monitor news and weather alerts

---
